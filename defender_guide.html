Windows Defender: disable or restore

A manual option if you want to see every change. If you only want to disable it, the simpler and safer option is the automatic script. Tested on Windows 11 IoT Enterprise 25H2 and 26H2.

Disables Defender, SmartScreen, and some Windows warnings on this system. You will need to restart twice: into Safe Mode and back. You do not need to turn off Tamper Protection.

Restores Defender to standard Windows values, not your original values: there is no backup here. If you need your original values, use the automatic script, it saves them.

1. Preparation

Normal mode

Step 1 · Scheduled tasks, notifications, SmartScreen

Open PowerShell as administrator (Win + X → Terminal (Admin)) and run the entire block. No restart is needed.

Write down the WdNisDrv value — you need it to restore: sc.exe qc WdNisDrv, the START_TYPE line. Use sc.exe: in PowerShell sc is Set-Content.

PowerShell · administrator 
# Disable Defender scheduled tasks
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Cache Maintenance"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Cleanup"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Scheduled Scan"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Verification"

# Disable the “Turn on security service” toast (AccountHealth)
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\AccountHealth\" -TaskName "RecoverabilityToastTask"

# Disable “Turn on Security Center service” tray notifications
reg add "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride       /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /t REG_DWORD /d 0 /f
reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /t REG_DWORD /d 0 /f

# Suppress Security Center “Defender is turned off” notifications
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications         /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications /t REG_DWORD /d 1 /f

# Disable SmartScreen
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\System"                     /v EnableSmartScreen         /t REG_DWORD /d 0   /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer"               /v SmartScreenEnabled        /t REG_SZ    /d Off /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost"                /v EnableWebContentEvaluation /t REG_DWORD /d 0   /f

# “Publisher could not be verified” dialog for downloaded files (for the current account)
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806 /t REG_DWORD /d 0 /f

Step 2 · Remove startup entry and prepare for Safe Mode

In the same PowerShell window, run the first block, then paste the identifier returned by bcdedit /copy.

PowerShell · administrator 
# Remove the Security Center icon from startup
Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" `
                    -Name "SecurityHealth" `
                    -ErrorAction SilentlyContinue

# Copy the current boot entry — you will need the GUID from the output below and in step 5
bcdedit /copy '{current}' /d "Defender Manual Safe Mode"

Saved in this browser. If the page is open on another device, enter the GUID there separately.

The identifier is inserted into the commands automatically. Run them one at a time and check for “The operation completed successfully” before the next one. If there is an error, do not restart.

PowerShell · administrator · 1/3 
bcdedit /set "{GUID}" safeboot minimal
PowerShell · administrator · 2/3 
bcdedit /displayorder "{GUID}" /remove
PowerShell · administrator · 3/3 
bcdedit /bootsequence "{GUID}"
Why copy the entry instead of setting a flag on the current one
PIN and Windows Hello do not work in Safe Mode; only your password works. A flag on the current entry would boot into Safe Mode every time until removed in WinRE. The copy is selected for one boot, hidden from the menu, and deleted in step 5; the original entry is unchanged.
Why Safe Mode is needed
Tamper Protection prevents even administrators from changing Defender service keys, and it does not load in Safe Mode. It does not protect tasks, notifications, or SmartScreen; step 1 disables those in normal mode.

Tamper Protection sometimes restores notification or SmartScreen values later. If the check in step 6 shows this, repeat step 1 in Safe Mode.
⟳ Restart into Safe Mode
  • Save your open work in other programs; the current application will not ask you to do so
  • You need your account password; PIN and Windows Hello sign-in do not work in Safe Mode
  • After signing in, return to this page and continue with the “Safe Mode” stage
  • Write down the GUID from the field above (on paper or in a screen photo): the field may be empty after restarting, and you need it to delete the temporary entry
PowerShell · administrator 
Restart-Computer

2. Safe Mode

Safe Mode

Step 3 · Grant permissions for the Sense key

regedit

The Sense service key is write-protected even from administrators. Without permissions, the command in step 4 will return “Access is denied”.

Open regedit: Win + R → regedit → Enter. Go to the key:

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Sense
  1. Right-click the folder → Permissions → Advanced
  2. Next to “Owner: SYSTEM” → Change → enter Administrators → Check Names → OK
  3. Select “Replace owner on subcontainers and objects” → Apply
  4. In the permissions list, select Administrators → Edit (if there is no such entry: Add → type Administrators → Check Names → OK) → Allow + Full control → Apply → OK

Step 4 · Disable services through the registry

Open cmd.exe as administrator (Win + R → cmd → Ctrl + Shift + Enter) and run the entire block. These commands are needed on every system.

ℹ 4 = “Disabled”. 2>nul in block [4/5] hides any errors from those lines; check the result in step 6.
cmd.exe · administrator, Safe Mode 
:: [1/5] Disable Defender services and kernel drivers
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend"  /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdFilter"  /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdBoot"   /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc" /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisDrv" /v Start /t REG_DWORD /d 4 /f

:: [2/5] Remove the Security Center shield from the tray
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray /t REG_DWORD /d 1 /f

:: [3/5] Suppress Health Center
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter /t REG_DWORD /d 1 /f

:: [4/5] Remove EPP from the File Explorer context menu
reg delete "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"                  /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"              /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"          /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP" /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"             /f 2>nul

:: [5/5] Block smartscreen.exe from starting (visible in Task Manager even when SmartScreen is disabled)
takeown /f "%SystemRoot%\System32\smartscreen.exe" /a
icacls "%SystemRoot%\System32\smartscreen.exe" /deny *S-1-5-32-545:(X)

Next, only for services present on your system. Verification: sc.exe qc service_name; if the response says the service does not exist, skip it.

cmd.exe · administrator, Safe Mode · if MDCoreSvc exists 
:: MDCoreSvc is a Defender platform service added by some Windows updates
reg add "HKLM\SYSTEM\CurrentControlSet\Services\MDCoreSvc" /v Start /t REG_DWORD /d 4 /f
cmd.exe · administrator, Safe Mode · if present, applies to 25H2+ 
reg add "HKLM\SYSTEM\CurrentControlSet\Services\Sense"               /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefsvc"       /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefusersvc"   /v Start /t REG_DWORD /d 4 /f
About WdBoot and Secure Boot
With Secure Boot and TPM enabled, the ELAM check may restore Start=0. This is normal: while WinDefend is disabled, Defender will not start.

Step 5 · Exit Safe Mode

Compare the GUID in the field above with the one returned by bcdedit /copy in step 2: the field may not have been saved. Then delete the temporary entry and restart.

cmd.exe · administrator, Safe Mode 
bcdedit /delete {GUID}
shutdown /r /t 0

3. Verification

Normal mode

Step 6 · Make sure everything is disabled

Run each block separately in PowerShell as administrator. Expected values are in the comments.

PowerShell · administrator 
# Scheduled tasks — all five State: Disabled
Get-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" | Select-Object TaskName, State
Get-ScheduledTask -TaskPath "\Microsoft\Windows\AccountHealth\" -TaskName "RecoverabilityToastTask" | Select-Object TaskName, State

# EPP in the context menu — all five "ERROR: The system was unable to find..."
reg query "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"

# Security Center notifications — AntiVirusDisableNotify and AntiVirusOverride should be 0x1
reg query "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify
reg query "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride

# “Defender is turned off” — both should be 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications

# SecurityAndMaintenance toast — Enabled should be 0x0 in both hives (step 1 wrote both)
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled

# SmartScreen — EnableSmartScreen 0x0, SmartScreenEnabled "Off", EnableWebContentEvaluation 0x0
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\System" /v EnableSmartScreen
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer" /v SmartScreenEnabled
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost" /v EnableWebContentEvaluation

# Publisher warning — 1806 should be 0x0
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806

# smartscreen.exe — deny ACL for Users should be present (in PowerShell use $env:, not %...%)
icacls "$env:SystemRoot\System32\smartscreen.exe"

# SecurityHealth startup — the key should NOT exist (an error is normal)
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SecurityHealth
PowerShell · administrator 
# Services — all Status: Stopped, StartType: Disabled; remove services not present on your system from the list (step 4)
Get-Service WinDefend, WdFilter, MDCoreSvc, WdNisSvc, WdNisDrv, Sense, webthreatdefsvc, webthreatdefusersvc |
  Select-Object Name, Status, StartType

# Security Center tray — HideSystray should be 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray

# Health Center — DisableHealthCenter should be 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter

After a Windows update, repeat the check: the update may restore the owner of smartscreen.exe or add a service (MDCoreSvc).

What to do after an update
Repeat the smartscreen.exe and MDCoreSvc commands from step 4 (in Safe Mode); you do not need to repeat step 3 because the Sense permissions remain. Defender remains disabled. Windows 10 was not tested.
⚠
Only CurrentControlSet is changed. 2>nul in commands hides any error on that line. If something was not restored, run that command without it.
If there are multiple boot configurations
Values in the other configurations remain disabled until they become current. The script is better for this case.

Normal mode

Step 1 · Enable tasks, notifications, EPP, and startup

Open cmd.exe as administrator (Win + R → cmd → Ctrl + Shift + Enter) and run the block. No restart is needed.

cmd.exe · administrator 
:: Re-enable Defender scheduled tasks
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Cache Maintenance" /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Cleanup"           /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Scheduled Scan"    /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Verification"      /Enable
schtasks /Change /TN "Microsoft\Windows\AccountHealth\RecoverabilityToastTask"               /Enable

:: Restore Security Center notifications
reg delete "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride       /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /f 2>nul
reg delete "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications         /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\System"           /v EnableSmartScreen         /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer"   /v SmartScreenEnabled        /f 2>nul
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost"    /v EnableWebContentEvaluation /f 2>nul

:: Restore the downloaded file publisher warning
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806 /f 2>nul

:: Remove the deny ACL on smartscreen.exe (disable step 4) — Administrators will remain the owner,
:: not the original owner; Windows will take ownership back over time
takeown /f "%SystemRoot%\System32\smartscreen.exe" /a
icacls "%SystemRoot%\System32\smartscreen.exe" /remove:d *S-1-5-32-545

:: Restore EPP to the File Explorer context menu
:: CLSID {09A47860-11B0-4DA5-AFA5-26D86198A780} = ShellExtension of the MpShe.dll module
reg add "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"                  /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"              /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"          /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP" /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"             /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f

:: Restore the Security Center icon to startup — carets preserve %windir% literally; without them
:: cmd.exe expands it before reg add, and the key contains the expanded path instead of the placeholder
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SecurityHealth /t REG_EXPAND_SZ /d "^%windir^%\System32\SecurityHealthSystray.exe" /f

2. Safe Mode

Safe Mode

Step 3 · Restore services through the registry

Open cmd.exe as administrator in Safe Mode and run the block. Do not restart: first restore the Sense owner through regedit below, then enter the exit commands.

ℹ
The block lists factory values. For WdNisDrv, use the value you wrote down when disabling it (step 1), if it differs from 3.
About WdBoot
The factory value is Start=0. With Secure Boot and TPM, the ELAM check may restore 0 automatically; this is normal.
cmd.exe · administrator, Safe Mode 
:: [1/3] Restore factory settings for all Defender services
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend"           /v Start /t REG_DWORD /d 2 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdFilter"           /v Start /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdBoot"            /v Start /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc"          /v Start /t REG_DWORD /d 3 /f
:: WdNisDrv: 3, unless you recorded a different value when disabling
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisDrv"          /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\Sense"              /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefsvc"    /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefusersvc" /v Start /t REG_DWORD /d 2 /f

:: [2/3] Restore the Security Center icon to the tray
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray /f 2>nul

:: [3/3] Re-enable Health Center
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter /f 2>nul

MDCoreSvc — only if you disabled it in disable step 4. Otherwise skip it:

cmd.exe · administrator, Safe Mode · if you disabled it 
reg add "HKLM\SYSTEM\CurrentControlSet\Services\MDCoreSvc" /v Start /t REG_DWORD /d 2 /f

Step 4 · Restore the owner of the Sense key

regedit

Only needed if you performed disable step 3. Otherwise, or if the key owner is already SYSTEM, skip it.

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Sense
  1. Right-click the folder → Permissions → Advanced
  2. If the list contains the Administrators entry added in disable step 3 → Remove
  3. Next to “Owner” → Change → enter SYSTEM → Check Names → OK → select “Replace owner on subcontainers and objects” → Apply → OK
  4. Close the permissions window

This method cannot restore the original key permissions; only the script can do that.

Step 5 · Exit Safe Mode

Compare the GUID in the field above with the one returned by bcdedit /copy in step 2: the field may not have been saved. Then delete the temporary entry and restart.

cmd.exe · administrator, Safe Mode 
bcdedit /delete {GUID}
shutdown /r /t 0
