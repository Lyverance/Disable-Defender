Windows Defender: отключить или восстановить

Ручной вариант для тех, кто хочет видеть каждое изменение. Если нужно просто отключить — проще и безопаснее автоматический скрипт. Проверено на Windows 11 IoT Enterprise 25H2 и 26H2.

Отключает Defender, SmartScreen и часть предупреждений Windows для текущей системы. Потребуются две перезагрузки: в безопасный режим и обратно. Tamper Protection выключать не нужно.

Возвращает Defender к типовым значениям Windows, а не к твоим исходным: бэкапа здесь нет. Если нужны именно исходные — используй автоматический скрипт, он их сохраняет.

1. Подготовка

Обычный режим

Шаг 1 · Задачи планировщика, уведомления, SmartScreen

Открыть PowerShell от администратора (Win + X → Терминал (администратор)) и выполнить блок целиком. Перезагрузка не нужна.

Запиши значение WdNisDrv — оно нужно при восстановлении: sc.exe qc WdNisDrv, строка START_TYPE. Именно sc.exe: в PowerShell sc — это Set-Content.

PowerShell · администратор 
# Отключить задачи планировщика Defender
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Cache Maintenance"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Cleanup"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Scheduled Scan"
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" -TaskName "Windows Defender Verification"

# Отключить тост «Включить службу безопасности» (AccountHealth)
Disable-ScheduledTask -TaskPath "\Microsoft\Windows\AccountHealth\" -TaskName "RecoverabilityToastTask"

# Отключить уведомления «Включить службу центра безопасности» из трея
reg add "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride       /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /t REG_DWORD /d 0 /f
reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /t REG_DWORD /d 0 /f

# Заглушить уведомления Security Center «Защитник выключен»
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications         /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications /t REG_DWORD /d 1 /f

# Отключить SmartScreen
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\System"                     /v EnableSmartScreen         /t REG_DWORD /d 0   /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer"               /v SmartScreenEnabled        /t REG_SZ    /d Off /f
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost"                /v EnableWebContentEvaluation /t REG_DWORD /d 0   /f

# Окно «Не удаётся проверить издателя» для скачанных файлов (для текущей учётной записи)
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806 /t REG_DWORD /d 0 /f

Шаг 2 · Убрать автозапуск и подготовиться к безопасному режиму

В том же PowerShell выполнить первый блок, затем вставить в поле ниже идентификатор, который вернул bcdedit /copy.

PowerShell · администратор 
# Убрать иконку Security Center из автозагрузки
Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" `
                    -Name "SecurityHealth" `
                    -ErrorAction SilentlyContinue

# Скопировать текущую загрузочную запись — GUID из вывода понадобится в поле ниже и в шаге 5
bcdedit /copy '{current}' /d "Defender Manual Safe Mode"

Сохраняется в этом браузере. Если страница открыта на другом устройстве, впиши GUID там отдельно.

Идентификатор подставится в команды сам. Выполняй по одной и проверяй «The operation completed successfully» перед следующей; при ошибке не перезагружайся.

PowerShell · администратор · 1/3 
bcdedit /set "{GUID}" safeboot minimal
PowerShell · администратор · 2/3 
bcdedit /displayorder "{GUID}" /remove
PowerShell · администратор · 3/3 
bcdedit /bootsequence "{GUID}"
Зачем копия записи, а не флаг на текущую
В безопасном режиме не работают PIN и Windows Hello — только пароль. Флаг на текущей записи отправлял бы в безопасный режим каждую загрузку, пока его не снимут из WinRE. Копия выбрана на одну загрузку, скрыта из меню и удаляется в шаге 5; настоящая запись не меняется.
Зачем вообще безопасный режим
Tamper Protection не даёт менять ключи служб Defender даже администратору, а в безопасном режиме он не загружается. Задачи, уведомления и SmartScreen им не защищены — их отключает шаг 1 в обычном режиме.

Иногда Tamper Protection позже возвращает значения уведомлений или SmartScreen. Если проверка (шаг 6) это покажет — повтори шаг 1 в безопасном режиме.
⟳ Перезагрузка в безопасный режим
  • Сохрани открытую работу в других программах — текущее приложение не спросит об этом
  • Нужен пароль учётной записи — вход по PIN и Windows Hello не работает в безопасном режиме
  • После входа вернись на эту страницу и продолжи с этапа «Безопасный режим»
  • Запиши GUID из поля выше (блокнот, фото экрана): после перезагрузки поле может оказаться пустым, а он нужен для удаления временной записи
PowerShell · администратор 
Restart-Computer

2. Безопасный режим

Безопасный режим

Шаг 3 · Выдать права на ключ Sense

regedit

Ключ службы Sense закрыт от записи даже администратору — без прав команда в шаге 4 вернёт «Отказано в доступе».

Открыть regedit: Win + R → regedit → Enter. Перейти к ключу:

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Sense
  1. Правая кнопка на папке → Разрешения → Дополнительно
  2. Напротив «Владелец: СИСТЕМА» → Изменить → ввести Администраторы → Проверить имена → ОК
  3. Галка «Заменить владельца субконтейнеров и объектов» → Применить
  4. В списке разрешений выбрать Администраторы → Изменить (если такой строки нет — Добавить → ввести Администраторы → Проверить имена → ОК) → Разрешить + Полный доступ → Применить → ОК

Шаг 4 · Отключить службы через реестр

Открыть cmd.exe от администратора (Win + R → cmd → Ctrl + Shift + Enter) и выполнить блок целиком — эти команды нужны на любой системе.

ℹ 4 = «Отключено». 2>nul в блоке [4/5] прячет любую ошибку этих строк — результат проверяется в шаге 6.
cmd.exe · администратор, безопасный режим 
:: [1/5] Отключить службы и драйверы ядра Defender
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend"  /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdFilter"  /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdBoot"   /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc" /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisDrv" /v Start /t REG_DWORD /d 4 /f

:: [2/5] Убрать щит Security Center из трея
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray /t REG_DWORD /d 1 /f

:: [3/5] Заглушить Health Center
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter /t REG_DWORD /d 1 /f

:: [4/5] Убрать EPP из контекстного меню проводника
reg delete "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"                  /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"              /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"          /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP" /f 2>nul
reg delete "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"             /f 2>nul

:: [5/5] Заблокировать запуск smartscreen.exe (виден в диспетчере задач даже при отключённом SmartScreen)
takeown /f "%SystemRoot%\System32\smartscreen.exe" /a
icacls "%SystemRoot%\System32\smartscreen.exe" /deny *S-1-5-32-545:(X)

Дальше — только для служб, которые есть на твоей системе. Проверка: sc.exe qc имя_службы; ответ «служба не существует» — пропусти.

cmd.exe · администратор, безопасный режим · если есть MDCoreSvc 
:: MDCoreSvc — служба платформы Defender, которую добавляют некоторые обновления Windows
reg add "HKLM\SYSTEM\CurrentControlSet\Services\MDCoreSvc" /v Start /t REG_DWORD /d 4 /f
cmd.exe · администратор, безопасный режим · если есть, актуально для 25H2+ 
reg add "HKLM\SYSTEM\CurrentControlSet\Services\Sense"               /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefsvc"       /v Start /t REG_DWORD /d 4 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefusersvc"   /v Start /t REG_DWORD /d 4 /f
Про WdBoot и Secure Boot
При включённом Secure Boot и TPM проверка ELAM может вернуть Start=0. Это нормально: пока отключён WinDefend, Defender не запустится.

Шаг 5 · Выйти из безопасного режима

Сверь GUID в поле выше с тем, что вернул bcdedit /copy в шаге 2: поле могло не сохраниться. Затем удали временную запись и перезагрузись.

cmd.exe · администратор, безопасный режим 
bcdedit /delete {GUID}
shutdown /r /t 0

3. Проверка

Обычный режим

Шаг 6 · Убедиться, что всё отключено

Выполнить каждый блок отдельно в PowerShell от администратора. Ожидаемые значения — в комментариях.

PowerShell · администратор 
# Задачи планировщика — все пять State: Disabled
Get-ScheduledTask -TaskPath "\Microsoft\Windows\Windows Defender\" | Select-Object TaskName, State
Get-ScheduledTask -TaskPath "\Microsoft\Windows\AccountHealth\" -TaskName "RecoverabilityToastTask" | Select-Object TaskName, State

# EPP в контекстном меню — все пять "ERROR: The system was unable to find..."
reg query "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP"
reg query "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"

# Уведомления Security Center — AntiVirusDisableNotify и AntiVirusOverride должны быть 0x1
reg query "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify
reg query "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride

# «Защитник выключен» — оба должны быть 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications

# Тост SecurityAndMaintenance — Enabled должен быть 0x0 в обоих ульях (шаг 1 писал оба)
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled

# SmartScreen — EnableSmartScreen 0x0, SmartScreenEnabled "Off", EnableWebContentEvaluation 0x0
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\System" /v EnableSmartScreen
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer" /v SmartScreenEnabled
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost" /v EnableWebContentEvaluation

# Предупреждение об издателе — 1806 должен быть 0x0
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806

# smartscreen.exe — deny-ACL на Users должен присутствовать (в PowerShell так: $env:, а не %...%)
icacls "$env:SystemRoot\System32\smartscreen.exe"

# Автозапуск SecurityHealth — ключ НЕ должен существовать (ошибка = норма)
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SecurityHealth
PowerShell · администратор 
# Службы — все Status: Stopped, StartType: Disabled; убери из списка службы, которых нет на твоей системе (шаг 4)
Get-Service WinDefend, WdFilter, MDCoreSvc, WdNisSvc, WdNisDrv, Sense, webthreatdefsvc, webthreatdefusersvc |
  Select-Object Name, Status, StartType

# Трей Security Center — HideSystray должен быть 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray

# Health Center — DisableHealthCenter должен быть 0x1
reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter

После обновления Windows повтори проверку: оно может вернуть владельца smartscreen.exe или добавить службу (MDCoreSvc).

Что делать после обновления
Повтори команды smartscreen.exe и MDCoreSvc из шага 4 (в безопасном режиме); шаг 3 повторять не нужно — права на Sense сохраняются. Defender при этом остаётся выключенным. Windows 10 не проверялась.
⚠
Меняется только CurrentControlSet. 2>nul в командах прячет любую ошибку строки — если что-то не вернулось, выполни эту команду без него.
Если загрузочных конфигураций несколько
В остальных конфигурациях значения останутся отключёнными, пока они не станут текущими. Для такого случая лучше скрипт.

1. Подготовка

Обычный режим

Шаг 1 · Включить задачи, уведомления, EPP, автозапуск

Открыть cmd.exe от администратора (Win + R → cmd → Ctrl + Shift + Enter) и выполнить блок. Перезагрузка не нужна.

cmd.exe · администратор 
:: Включить задачи планировщика Defender обратно
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Cache Maintenance" /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Cleanup"           /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Scheduled Scan"    /Enable
schtasks /Change /TN "Microsoft\Windows\Windows Defender\Windows Defender Verification"      /Enable
schtasks /Change /TN "Microsoft\Windows\AccountHealth\RecoverabilityToastTask"               /Enable

:: Вернуть уведомления Security Center
reg delete "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusDisableNotify /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Security Center" /v AntiVirusOverride       /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /f 2>nul
reg delete "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings\Windows.SystemToast.SecurityAndMaintenance" /v Enabled /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableNotifications         /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v DisableEnhancedNotifications /f 2>nul
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\System"           /v EnableSmartScreen         /f 2>nul
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer"   /v SmartScreenEnabled        /f 2>nul
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\AppHost"    /v EnableWebContentEvaluation /f 2>nul

:: Восстановить предупреждение об издателе скачанного файла
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Zones\3" /v 1806 /f 2>nul

:: Снять deny-ACL на smartscreen.exe (шаг 4 отключения) — владельцем останутся Администраторы,
:: а не исходный владелец; Windows со временем заберёт его сама
takeown /f "%SystemRoot%\System32\smartscreen.exe" /a
icacls "%SystemRoot%\System32\smartscreen.exe" /remove:d *S-1-5-32-545

:: Вернуть EPP в контекстное меню проводника
:: CLSID {09A47860-11B0-4DA5-AFA5-26D86198A780} = ShellExtension модуля MpShe.dll
reg add "HKLM\SOFTWARE\Classes\*\shellex\ContextMenuHandlers\EPP"                  /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Drive\shellex\ContextMenuHandlers\EPP"              /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Directory\shellex\ContextMenuHandlers\EPP"          /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Directory\Background\shellex\ContextMenuHandlers\EPP" /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f
reg add "HKLM\SOFTWARE\Classes\Folder\shellex\ContextMenuHandlers\EPP"             /ve /d "{09A47860-11B0-4DA5-AFA5-26D86198A780}" /f

:: Вернуть иконку Security Center в автозапуск — каретки сохраняют %windir% буквально; без них
:: cmd.exe развернёт его до reg add, и в ключе окажется уже подставленный путь, а не плейсхолдер
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v SecurityHealth /t REG_EXPAND_SZ /d "^%windir^%\System32\SecurityHealthSystray.exe" /f

Шаг 2 · Подготовиться к безопасному режиму

В том же cmd выполнить первую команду, затем вставить в поле ниже идентификатор, который вернул bcdedit /copy.

cmd.exe · администратор 
bcdedit /copy {current} /d "Defender Manual Safe Mode"

Сохраняется в этом браузере.

Выполняй по одной и проверяй «The operation completed successfully» перед следующей; при ошибке не перезагружайся.

cmd.exe · администратор · 1/3 
bcdedit /set {GUID} safeboot minimal
cmd.exe · администратор · 2/3 
bcdedit /displayorder {GUID} /remove
cmd.exe · администратор · 3/3 
bcdedit /bootsequence {GUID}
⟳ Перезагрузка в безопасный режим
  • Сохрани открытую работу в других программах — текущее приложение не спросит об этом
  • Нужен пароль учётной записи — PIN и Windows Hello не работают в безопасном режиме
  • После входа вернись сюда и продолжи с этапа «Безопасный режим»
cmd.exe · администратор

2. Безопасный режим

Безопасный режим

Шаг 3 · Восстановить службы через реестр

Открыть cmd.exe от администратора в безопасном режиме и выполнить блок. Не перезагружайся — сначала верни владельца Sense через regedit ниже, и только потом вводи команды выхода.

ℹ
Заводские значения указаны в блоке. Для WdNisDrv подставь то, что записал при отключении (шаг 1), если оно отличается от 3.
Про WdBoot
Заводское значение — Start=0. При Secure Boot и TPM проверка ELAM может вернуть 0 сама — это нормально.
cmd.exe · администратор, безопасный режим 
:: [1/3] Восстановить заводские параметры всех служб Defender
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend"           /v Start /t REG_DWORD /d 2 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdFilter"           /v Start /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdBoot"            /v Start /t REG_DWORD /d 0 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc"          /v Start /t REG_DWORD /d 3 /f
:: WdNisDrv: 3, если при отключении не было другого
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisDrv"          /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\Sense"              /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefsvc"    /v Start /t REG_DWORD /d 3 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Services\webthreatdefusersvc" /v Start /t REG_DWORD /d 2 /f

:: [2/3] Вернуть иконку Security Center в трей
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Systray" /v HideSystray /f 2>nul

:: [3/3] Включить Health Center обратно
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows\HealthCenter" /v DisableHealthCenter /f 2>nul

MDCoreSvc — только если ты отключал её в шаге 4 отключения. Иначе пропусти:

cmd.exe · администратор, безопасный режим · если отключал 
reg add "HKLM\SYSTEM\CurrentControlSet\Services\MDCoreSvc" /v Start /t REG_DWORD /d 2 /f

Шаг 4 · Вернуть владельца ключа Sense

regedit

Нужно, только если ты выполнял шаг 3 отключения. Иначе, или если владелец ключа уже СИСТЕМА, пропусти.

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Sense
  1. Правая кнопка на папке → Разрешения → Дополнительно
  2. Если в списке есть строка Администраторы, добавленная в шаге 3 отключения → Удалить
  3. Напротив «Владелец» → Изменить → ввести СИСТЕМА → Проверить имена → ОК → галка «Заменить владельца субконтейнеров и объектов» → Применить → ОК
  4. Закрыть окно разрешений

Исходные права ключа этим способом не вернуть — это умеет только скрипт.

Шаг 5 · Выйти из безопасного режима

Сверь GUID в поле выше с тем, что вернул bcdedit /copy в шаге 2: поле могло не сохраниться. Затем удали временную запись и перезагрузись.

cmd.exe · администратор, безопасный режим 
bcdedit /delete {GUID}
shutdown /r /t 0
Отметки шагов и введённые GUID хранятся только в этом браузере.
