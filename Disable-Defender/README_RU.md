# 🛡️ Чистое отключение Windows Defender

Нативный, безопасный и полностью обратимый метод отключения Защитника Windows — без удаления файлов и стороннего софта.

Тестировалось на **Windows 11 IoT Enterprise 25H2**. Должно работать на других редакциях Windows 10/11, но не проверялось.

> ⚠️ **Дисклеймер:** Проект разрабатывался для личного использования и тестировался на моей системе. Вы используете эти скрипты на свой страх и риск.

---

## ❓ Почему не Defender Remover / Killer и подобные инструменты

Такие утилиты физически удаляют компоненты Defender из `WinSxS`. Последствия:

- Накопительные обновления падают с ошибкой `0x800f081f` — Windows не находит файлы при проверке целостности
- `sfc /scannow` и `DISM` либо не работают, либо восстанавливают Defender в сломанном состоянии
- Откат через бэкап ненадёжен — при сбое только переустановка

Этот метод не трогает ни одного файла — только реестр. Обновления работают штатно, откат занимает один запуск скрипта.

## ⚙️ Инструкция (Способ А)

### Отключение

**Шаг 0 — обязательный ручной шаг**
Отключите Tamper Protection вручную:
*Параметры ➔ Конфиденциальность и безопасность ➔ Безопасность Windows ➔ Защита от вирусов и угроз ➔ Управление параметрами ➔ Защита от несанкционированного доступа ➔ Откл.*

**Шаг 1 — обычный режим**
Дважды кликните `Disable-Defender.cmd`. Скрипт запросит права через UAC, выполнит подготовку и перезагрузит ПК в Безопасный режим.

**Шаг 2 — Safe Mode**
Консоль откроется автоматически. Скрипт отключит службы и вернёт систему в обычный режим. Ручных действий не требуется.

### Восстановление

Дважды кликните `Restore-Defender.cmd`. Скрипт восстановит исходное состояние системы и перезагрузит ПК. После этого включите Tamper Protection обратно.

### Проверка статуса

Дважды кликните `Check-Status.cmd` — откроется отчёт о состоянии всех компонентов Defender.

> ℹ️ **Крупные обновления Windows (Feature Update)** могут вернуть Defender в исходное состояние. После такого обновления запустите `Check-Status.cmd` и при необходимости повторите отключение. Обычные накопительные обновления (Cumulative Update) это не затрагивает.

| Компонент | Что именно |
|---|---|
| **Ядро Defender** | WinDefend, WdFilter, WdBoot, WdNisSvc, WdNisDrv |

| **Уведомления** | Security Center, HealthCenter |
