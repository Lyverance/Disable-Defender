# Contributing

Bug reports are the most useful contribution. Use the bug report form and include your Windows edition and build, the tool version and the output of "Check protection status".

Pull requests are welcome for fixes. Please keep a change small and say on which Windows edition and build you tested it. The tool changes the registry and service settings, so an untested change will not be merged.

The tool deletes and replaces no Windows files; changes that would are out of scope.
